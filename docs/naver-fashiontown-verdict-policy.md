# 네이버 패션타운 최종 판정 기준

네이버 패션타운은 상품코드 검색 결과의 판매처 유형 라벨만 최종 판정 근거로 사용한다.

- `브랜드직영몰`, `백화점`, `아울렛` 중 하나라도 상품 결과 카드의 판매처 유형에서 확인되면 `확인완료`.
- 세 유형이 하나도 확인되지 않으면 추가 상품 카드 분석이나 보조 판정 없이 `상품없음`.
- 상단 채널 탭의 건수(예: `브랜드직영몰 1개`)는 최종 판정 근거로 사용하지 않는다.
- 일반 판매처, 해외직구, 구매대행 등은 위 공식 유통 유형 근거로 인정하지 않는다.

이 규칙은 네이버 패션타운의 고정 판정 정책이다.
