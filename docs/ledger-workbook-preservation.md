# 원본 장부 가져오기와 엑셀 내보내기

기존 어라운드지 Google 장부의 입력 내용을 변경하지 않고 프로그램에서 조회·편집하고 내보내기 위한 기능입니다. 새 구매 자동 기록의 금액 검증 문제와는 별개입니다.

- 모든 탭의 원래 순서, 이름, 숨김 상태와 표시값·수식을 저장합니다.
- 중복 행, 공백, 앞자리 0, 오류 표시를 정규화하거나 수정하지 않습니다.
- 화면에는 최대 100행씩 표시하며 다음 페이지로 전체 입력 행을 볼 수 있습니다. 숨김 탭은 표시 옵션으로 볼 수 있습니다.
- Google이 생성한 전체 XLSX를 암호화해 보관합니다. 내보내기는 이 데이터를 재계산하거나 재생성하지 않고 그대로 저장하며 SHA-256으로 저장 후 검증합니다.
- 화면은 셀 선택 후 문자·숫자·날짜·체크값·수식을 편집할 수 있는 표입니다. 기존 목록/범위 드롭다운 값을 선택할 수 있습니다. 행·열 삽입/삭제, 이미지 편집 등 Google Sheets의 모든 편집 기능을 재현하는 엔진은 아닙니다. 해당 정보의 Excel 보존 범위는 Google의 XLSX 변환 결과에 따릅니다.
- 금액이나 세무상 적정성을 보증하는 검증이 아닙니다. 기존 입력 오류도 그대로 유지합니다.

## 연결 업데이트

`services/google-ledger-apps-script.gs`의 업데이트된 연결 코드에 `workbook.read.v1`, `workbook.edit.v1` 기능이 있습니다. 가져오기는 원래 장부 파일을 편집하지 않으며 연결 스크립트의 새 버전 배포가 필요합니다. 새 기능은 Drive 읽기와 UrlFetch 권한을 사용하므로 기존 배포의 권한 상태를 확인해야 합니다. 실제 연결 주소나 보안키, 장부 데이터는 저장소에 넣지 않습니다.

이전 연결 코드는 POST를 구매 기록으로 처리할 수 있으므로, 프로그램은 GET 기능 확인에 성공한 후에만 읽기 요청을 보냅니다. 연결 코드가 구버전이면 POST를 보내지 않습니다.

연결이 업데이트된 프로그램에서 `구매 장부 → Google 장부 그대로 가져오기`를 실행합니다. 가져오는 동안 원본 수정 시각이 바뀌면 중단하며 기존 캐시를 유지합니다. 성공한 캐시는 사용자 데이터 폴더에 운영체제 암호화로 저장되며 일반 소싱 데이터/저장소에 포함하지 않습니다.

## 검증 범위

회귀 테스트는 표시값·수식·숨김 탭·중복 행 보존, 암호화 저장/읽기, 원본 Excel 바이트의 내보내기 일치, 손상 데이터의 기존 파일 보호, 모든 행 페이지 접근, 구버전 연결에 대한 POST 차단을 검증합니다. 실제 사용자 PC에서의 연결 권한·Google 원본 데이터 가져오기·Excel 실행 검증은 별도입니다. 기존 구매 자동 기록 기능의 알려진 금액/수량/중복/반품 문제를 이 변경으로 해결했다고 간주하지 않습니다.


## 프로그램 안에서 편집

셀을 클릭하거나 키보드 Enter로 선택하고 입력 형식과 내용을 확인한 뒤 `선택한 셀 저장`을 누릅니다. 금액·수량은 통화기호·배송비 문구를 제거해 합치는 방식으로 해석하지 않습니다. 숫자는 정규 표기, 유효성 및 15자리 정밀도 범위를 검사하고 임의 반올림 없이 Google에 전달합니다. 문자로 입력한 앞자리 0과 `=` 문자는 문자 그대로 보존하며 수식 입력은 별도 유형으로 구분합니다. 날짜는 장부 시간대 기준 YYYY-MM-DD를 사용합니다.

가져온 시점의 원본 수정 시각과 셀의 이전 값/수식이 달라지면 쓰기를 거절합니다. 앱의 쓰기는 ScriptLock으로 직렬화하며, 동시에 사람이 Google에서 편집하는 행위까지 트랜잭션으로 잠그는 기능은 아닙니다. 보호된 셀, 병합 범위의 비기준 셀, 지원하지 않는 입력 규칙의 셀은 쓰지 않습니다. 목록/범위/체크박스 규칙은 값 검증 후 유지합니다. 값 변경은 해당 셀에만 적용하며 원래 서식과 수식의 일괄 수정·복사는 하지 않습니다. 수식 의존 셀의 계산 결과는 Google Sheets가 재계산합니다.

서버가 수정 셀의 값/수식을 다시 읽어 일치 여부를 확인하고 전체 장부 및 Google XLSX를 새로 받아 암호화 캐시에 저장해야 완료로 표시합니다. 저장 요청 전 로컬 미확인 표식을 남겨, 응답 유실·후속 읽기 실패·재시작 때도 예전 엑셀 내보내기를 차단합니다. 사용자가 `Google 장부 그대로 가져오기`로 다시 확인하면 차단이 해제됩니다. 쓰기는 자동 재시도하지 않습니다.

실제 Google 장부에는 개발 중 시험 쓰기를 수행하지 않습니다. 배포된 Apps Script의 새 기능·권한과 사용자 PC의 실제 저장 및 Excel 열기 검증이 필요합니다.
