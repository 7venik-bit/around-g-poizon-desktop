# 원본 장부 가져오기와 엑셀 내보내기

기존 어라운드지 Google 장부의 입력 내용을 변경하지 않고 프로그램에서 조회하고 내보내기 위한 기능입니다. 새 구매 자동 기록의 금액 검증 문제와는 별개입니다.

- 모든 탭의 원래 순서, 이름, 숨김 상태와 표시값·수식을 저장합니다.
- 중복 행, 공백, 앞자리 0, 오류 표시를 정규화하거나 수정하지 않습니다.
- 화면에는 최대 100행씩 표시하며 다음 페이지로 전체 입력 행을 볼 수 있습니다. 숨김 탭은 표시 옵션으로 볼 수 있습니다.
- Google이 생성한 전체 XLSX를 암호화해 보관합니다. 내보내기는 이 데이터를 재계산하거나 재생성하지 않고 그대로 저장하며 SHA-256으로 저장 후 검증합니다.
- 화면은 읽기 전용 표입니다. 셀 병합, 이미지, 드롭다운 조작 등 Google Sheets의 편집 기능 전체를 재현하는 스프레드시트 엔진은 아닙니다. 해당 정보의 Excel 보존 범위는 Google의 XLSX 변환 결과에 따릅니다.
- 금액이나 세무상 적정성을 보증하는 검증이 아닙니다. 기존 입력 오류도 그대로 유지합니다.

## 연결 업데이트

`services/google-ledger-apps-script.gs`의 업데이트된 연결 코드에 `workbook.read.v1` 기능이 있습니다. 원래 장부 파일은 편집하지 않으며 연결 스크립트의 새 버전 배포가 필요합니다. 새 기능은 Drive 읽기와 UrlFetch 권한을 사용하므로 기존 배포의 권한 상태를 확인해야 합니다. 실제 연결 주소나 보안키, 장부 데이터는 저장소에 넣지 않습니다.

이전 연결 코드는 POST를 구매 기록으로 처리할 수 있으므로, 프로그램은 GET 기능 확인에 성공한 후에만 읽기 요청을 보냅니다. 연결 코드가 구버전이면 POST를 보내지 않습니다.

연결이 업데이트된 프로그램에서 `구매 장부 → Google 장부 그대로 가져오기`를 실행합니다. 가져오는 동안 원본 수정 시각이 바뀌면 중단하며 기존 캐시를 유지합니다. 성공한 캐시는 사용자 데이터 폴더에 운영체제 암호화로 저장되며 일반 소싱 데이터/저장소에 포함하지 않습니다.

## 검증 범위

회귀 테스트는 표시값·수식·숨김 탭·중복 행 보존, 암호화 저장/읽기, 원본 Excel 바이트의 내보내기 일치, 손상 데이터의 기존 파일 보호, 모든 행 페이지 접근, 구버전 연결에 대한 POST 차단을 검증합니다. 실제 사용자 PC에서의 연결 권한·Google 원본 데이터 가져오기·Excel 실행 검증은 별도입니다. 기존 구매 자동 기록 기능의 알려진 금액/수량/중복/반품 문제를 이 변경으로 해결했다고 간주하지 않습니다.
